## 四、遗留风险（不阻塞，进实施期验证清单）

1. **qwen3-embedding 查询指令格式**：`Instruct: ...\nQuery: ...` 格式以官方模板为准，**必须在 golden set 上实测 Hit@5**，并与硅基流动 bge-m3 API 版本跑一次对照——这本来就是评测计划第 4 周的单变量实验，正好落位。
2. **TEI CPU 吞吐**：3–8s/评分项（top20 候选）是估算值，第 4 周实测；不达标则候选降 12（03 §5.4 已写入该开关）。
3. **zhparser 自建镜像**：DDL 依赖 `CREATE EXTENSION zhparser`，官方 pgvector 镜像不含该扩展——下一步 docker-compose 必须含自建 Dockerfile（Debian + 编译 zhparser/SCWS），这是环境落地的第一个硬任务。
4. **Ollama num_ctx 静默截断**：已列入启动自检七项，但批量嵌入路径（离线管道）与查询路径（在线链路）要分别探针验证。
